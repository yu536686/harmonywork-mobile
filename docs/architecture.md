# Android 首版架构决策

日期：2026-09-30；来源：当前对话已确认的产品方向。

1. Android 优先开发测试，iOS 在早期验证生命周期和原生插件。
2. 手机拥有独立的主会话与轻量 Agent；模型通过个人账户 API 配置调用，不要求本地模型推理。
3. 手机处理目标与约束，电脑自主执行完整子任务，避免每一步依赖手机持续在线。
4. 协调服务负责可信设备绑定、任务持久化、去重、状态恢复、权限与成果索引。
5. 会话和个人记忆属于账户层；电脑本地执行记录和项目资源按授权访问。
6. 首版 HTTPS/WSS 传递任务与进度，附件独立上传下载；P2P 不作为首个闭环的依赖。
7. 技术候选 Tauri 2 + React + TypeScript + Rust，单独验证通知、凭证存储、文件分享、后台恢复和未来 P2P 集成。
8. 新建独立 Git 仓库，主分支为 main，不复用桌面仓库的 Git worktree，避免把移动端引入桌面发布链。

## 首个验收闭环

- 电脑离线时，手机仍可使用账户模型对话。
- 电脑在线时，手机可提交一个有明确输入、目标和交付要求的任务。
- 服务端确认持久化接收后，手机退出不影响桌面继续执行。
- 手机重新打开后恢复任务状态，并能下载真实成果。

第一阶段已实现账号加密云设置恢复和手机独立文本对话，并完成 MuMu 登录页启动验证。上述远端任务闭环、真实账户登录与模型回复尚未完成端到端验收；不得将入口页视为已实现远端功能。
